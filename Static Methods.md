**Static Methods**





static function can be called without creating any object

and only static variables are accessible inside static funtions. normal variables are not accessible inside static methods



static keyword is used for   constant memory allocation

it is used to make function ,  variables and  blocks as  static



static blocks are executed before the main function

ex.

static {

System.out..("hello ");

}



and only static variables are accessible within static blocks and functions the nonstatic variables are not accessible
